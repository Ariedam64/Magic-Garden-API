Magic Garden data

The unofficial REST API for Magic Garden. Grab plants, pets, items and sprites, follow the weather and shops as they change, and dig into the stats history. No key, no signup, just call it.

endpoints Real-time SSE streams Historical stats CSV / TSV export
Quick start 
# All game data (plants, pets, items…)
curl /data

# Real-time stream (SSE)
curl -N /live/stream

# Sprite catalog, ready-to-use PNG urls
curl /assets/sprites?cat=seeds
